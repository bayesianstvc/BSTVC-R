综合判断模型拟合度、复杂度与预测精度

model.evaluation 汇总 DIC、WAIC、eff、pd2 与 LS。比较候选模型时，DIC 与 WAIC 越小通常表示拟合表现越好；eff 与 pd2 反映有效参数和模型复杂度；LS 越接近 0，预测精度通常越高。

表格与地图的空间唯一标识字段需名称、类型一致；缺失值统一用 NA 表示。

辅助工具

内置数据转换、字段转换和自定义空间矩阵，支持宽表转长表与字段数值化。

DESKTOP + R PACKAGE GUIDE

建模参数应与研究设计逐项对应

数据来源

空间顺序未变化选“原始数据”；完成自动重排后选“检查后数据”。

变量与索引

指定响应变量 Y、一个或多个解释变量 X、Time 字段与 Space 字段。

响应类型

根据数据特征选择 continuous、binary 或 count；不同类型对应不同似然。

计算设置

建议解释变量标准化；默认线程数为 6；空间权重可用默认 QUEEN-B 或自定义矩阵。

数据规模

  • 多个进程按 PID、开始时间和运行时长区分
THREAD SETTING EVIDENCE

用相近模型比较线程参数，而不是盲目加线程

线程数越高不一定越快。结合持续 CPU 活动、内存压力、波动程度和模型求解时间，寻找适合当前电脑或工作站的平衡点；默认线程参数仍为 6。

  • 过去一小时或全部采集数据时间窗
  • 综合资源表现分用于相对比较
  • 已结束进程仍保留并明确标记
LOCAL-ONLY / PRIVACY

资源记录留在本机，方便复盘与复现

  • 默认目录：%LOCALAPPDATA%\INLA-Resource-Monitor\runs
  • 可自定义输出目录、采样间隔和阈值
  • 无需管理员账户，不永久修改 PowerShell 执行策略
