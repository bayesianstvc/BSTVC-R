CORE 01 / STVC时空独立非平稳假设

同时量化 Y 与多个 X 之间的空间和时间异质关联，并纳入空间、时间自相关；适合解析结构化时空非平稳性。

CORE 02 / STIVC时空交互非平稳假设

通过空间分层异质性 SSH 或时间分层异质性 TSH 定义交互随机效应，适配县—省、日—月等两层耦合数据，并控制模型复杂度。

CORE 03 / STVPI时空相对重要性

以方差分割把异质影响转化为可解释百分比，既可筛选关键因素，也可区分时间与空间贡献来源。

DESKTOP + R PACKAGE GUIDE

把表格与地图组织成可验证的时空面板

文件

支持 CSV、XLSX、XLS；地图需导入完整 Shapefile 文件集合，不能只提供 .shp。

空间顺序

每个时间截面的空间单元顺序应与地图一致；桌面版可自动比对、重排并导出检查后数据。

字段

表格与地图的空间唯一标识字段需名称、类型一致；缺失值统一用 NA 表示。

辅助工具

内置数据转换、字段转换和自定义空间矩阵，支持宽表转长表与字段数值化。

DESKTOP + R PACKAGE GUIDE

建模参数应与研究设计逐项对应

数据来源

空间顺序未变化选“原始数据”；完成自动重排后选“检查后数据”。

变量与索引

指定响应变量 Y、一个或多个解释变量 X、Time 字段与 Space 字段。

响应类型

根据数据特征选择 continuous、binary 或 count；不同类型对应不同似然。

计算设置

建议解释变量标准化；默认线程数为 6；空间权重可用默认 QUEEN-B 或自定义矩阵。

DESKTOP + R PACKAGE GUIDE

一次运行形成完整的解释证据包

model.evaluation

DIC、WAIC、eff、pd2、LS 等模型拟合、复杂度与预测评价。

local.prediction

局部预测、缺失值填补结果，以及 50% / 95% 贝叶斯可信区间。

random effects

解释变量的空间随机效应、时间随机效应与相应可信区间。

TCs / SCs / STVPI

时间系数、空间系数与相对时空贡献百分比；可一次下载为多 Sheet Excel。

DESKTOP + R PACKAGE GUIDE

在正式研究前先理解当前版本边界

数据规模

上传上限设置为 1GB；计算量随空间单元、时间点、解释变量、响应类型和线程设置增加。

空间矩阵

点地图建议使用距离或 k 近邻；若 k 近邻矩阵出现 INLA 报错，可调整构建方式或更换矩阵类型。

STVPI

当前二分类与计数模型未包含残差项，因此暂不能计算整体模型的解释百分比。

非平稳假设

当前 BSTVC 默认全部解释变量具有时空非平稳性；更灵活的变量级设定属于后续扩展方向。

监视一个或多个 inla.exe，持续记录整机 CPU、内存、线程、PID、运行时长和进程状态；主 CPU 曲线采用可直接对照 Windows 任务管理器的整机口径。

  • CPU mean / P95 / 高于阈值比例
  • 当前与峰值线程数、内存占用
  • 多个进程按 PID、开始时间和运行时长区分
THREAD SETTING EVIDENCE

用相近模型比较线程参数，而不是盲目加线程

线程数越高不一定越快。结合持续 CPU 活动、内存压力、波动程度和模型求解时间，寻找适合当前电脑或工作站的平衡点；默认线程参数仍为 6。

  • 过去一小时或全部采集数据时间窗
  • 综合资源表现分用于相对比较
  • 已结束进程仍保留并明确标记
LOCAL-ONLY / PRIVACY

资源记录留在本机，方便复盘与复现

监视器通过 PowerShell 和浏览器本地运行，不需要云端服务，也不会上传进程数据；每次运行可保存 CSV、JSON 与本地 HTML 报告。

  • 默认目录：%LOCALAPPDATA%\INLA-Resource-Monitor\runs
  • 可自定义输出目录、采样间隔和阈值
  • 无需管理员账户，不永久修改 PowerShell 执行策略

THREAD DECISION

建议从默认 6 线程开始。 内存充足且单次任务规模较大时再尝试 8 线程；12 线程仅建议用于高核心数、高内存设备，并用监视器确认系统仍有稳定余量。
